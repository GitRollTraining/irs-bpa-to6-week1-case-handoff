# Case handoff workbench

Build a browser workspace for Northstar Services, a fictional operations team.

1. Read the client brief in CLIENT_BRIEF.md.
2. Read the course and submission guide in LEARNER_GUIDE.md.
3. Choose **Use this template** to create your own repository, then build the application.

This repository contains the assignment documents only. Use FastAPI and uv as required by the
course; you create the project and its working environment. Use fictional information only.
The trainer provides approved service access and the current data/tool policy separately.

Continue your completed project and saved information in Week 2. There is no second starter.
Disclose any reused code or material, including material from earlier versions of this repository.
